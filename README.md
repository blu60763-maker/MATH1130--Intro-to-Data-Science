# MATH 1130: Introduction to Data Science

## Overview
This repository contains coursework, data analysis, and projects completed for **MATH 1130: Introduction to Data Science**. The assignments focus on end-to-end data science workflows, including data cleaning, exploratory data analysis (EDA), statistical visualization, and feature engineering for machine learning.

---

## Assignments & Projects

* **`A1-Overwatch League Insights`**  
  Data cleaning, EDA, performance metric evaluation and visualization of match and tournament dynamics across teams and map formats in the Overwatch League.

* **`A2-Air Pollution Health Effects`**  
  Investigation into the plausible impacts of global air contamination on public health using multi-source environmental and demographic datasets from the WHO, IHME, and the World Bank.

* **`A3-Amazon Reviews NLP`**  
  Natural language processing (NLP) and contextual feature engineering on large-scale Amazon review datasets to identify key drivers of customer sentiment.
